# Exercícios de Teste Unitário — Maven

Projeto Java Maven com JUnit 5, organizado para importar no Eclipse.

## Importar no Eclipse
1. Extraia o ZIP.
2. Abra **File > Import > Maven > Existing Maven Projects**.
3. Em **Root Directory**, selecione a pasta extraída que contém `pom.xml`.
4. Clique em **Finish**.
5. Se necessário, clique com o botão direito no projeto > **Maven > Update Project**.

## Executar
Botão direito no projeto > **Run As > Maven test**.

O projeto está configurado para Java 21. No exercício 2, o PDF só especifica as respostas de verão e inverno; foram acrescentadas descrições simples para outono e primavera. No exercício 4, a idade de 21 anos foi incluída em adulto para não ficar sem categoria.
